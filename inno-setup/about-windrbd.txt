What is WinDRBD?
================

WinDRBD is a port of the LINBIT® Distributed Replicated Block Device
(DRBD®) Linux driver to Microsoft Windows. It is wire-compatible
with the Linux version and supports almost all features of the
Linux version.

DRBD itself is used to build high-availability (HA) clusters by replicating
contents of one block device over a network to (up to 31) other nodes.

To get professional support for WinDRBD contact
sales@linbit.com directly.

To learn how to use WinDRBD to create a 2-node HA cluster based
on Microsoft Windows (or ReactOS) please go to https://www.linbit.com
and download the WinDRBD tech guide (Resources/User Guides).
You might also find the articles on https://kb.linbit.com useful.

Note that larger deployments (more than 2 nodes, more than a
handful resources) are best managed with LINSTOR which also supports
the Windows platform.

WinDRBD is open source software and licensed under the GNU general public

https://www.github.com/LINBIT/WinDRBD
